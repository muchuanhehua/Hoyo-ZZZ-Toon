# 使用流程

## 角色管理

顶行依次为导入模型、完整主体选择、骨骼显示。选择框仅接受有唯一骨架和可渲染网格的 MMD 根主体。视图中选中角色子网格或骨架时会同步主体；选择普通物体不会把目标改成骨骼或场景物件。

已有 MMD 模型点击“应用材质”时自动接入，无需手动扫描。新导入由 MMD Tools 执行，保留骨架、权重、UV、Morph、物理和源材质；不自动载入背景。没有相机时创建全身相机，有相机时保留。

## 材质

0.8.1 已撤回 0.8.0 的头发高光扩缩与新增面板，恢复此前效果。从 0.8.0 更新后点击一次“更新材质”，清理扩缩节点与未被复用的派生图；其他调色、描边和透眼保留。

FBX 目录是可选输入。空目录可直接应用基础渲染；指定后读取 FBX 材质引用、几何 UV 与 Materials 中的脸影引用，自动对应 Textures。源文件只读，不导入 FBX 对象，不写单角色风格参数。

首次应用会补齐缺失的主光与相机，并启用 Eevee / Standard 和场景灯光材质预览；不会新建预览场景或修改输出分辨率。常用控制为：

- 阴影位置：联动身体和基础脸影的明暗位置；SDF 的方向由原始脸影图和主光控制。
- 明暗过渡：联动身体与基础脸影的软硬度；保留 SDF 原始方向曲线。
- 衣料光泽：控制现有宽反射强度。
- 描边粗细：无单位倍率。1 对应身高 0.15%，0 关闭；角色尺寸不同仍保持相对宽度。
- 刘海透眼：自动识别前刘海，正面透出实际可见的眼部，侧面逐渐淡出；0 关闭透出。按 F12 查看完整效果。

“描边与透眼”默认折叠。相机约束描边默认开启，可限制最大像素宽度；眉睫比例和正侧面淡出角度可单独调整。无需手工创建辅助对象、选刘海面或运行文本脚本。

透眼的辅助可见性保留眼皮、其他头发、手、其他角色及场景物体的遮挡，并读取标准闭眼形态键。没有可靠脸、虹膜或前刘海区域时，说明中会记录未启用原因。多个角色各自管理自己的透眼，不借用另一个角色的眼部。

辅助场景与合成数据由插件管理，保留接入前已有合成器的后处理；不需要在原生场景下拉框切换辅助场景。每个启用透眼的角色会增加可见性渲染开销，材质预览不显示完整的最终合成。

0.7.1 修复 0.7.0 中透明脸部未参与眼部通道遮挡引起的灰白块。辅助计算会为需要写入深度的透明材质建立独立副本；主画面材质与源数据保留。旧工程选择主体点击一次“更新材质”，再按 F12 查看。

这些参数应用后实时更新。更换资源目录、修正用途后点击“更新材质”。重置参数保留资源绑定及局部调色；恢复原材质还原源网格和材质，场景、灯光与相机独立保留。

脸部与身体皮肤使用同一套肤色基准、场景遮挡和光色响应。0.6.3 默认恢复此前偏粉的亮面和暗部。旧工程点击“更新材质”时迁移 0.6.1／0.6.2 的中性默认配色，其他自定义配色、统一肤色调节与局部调色保留。

PMX Toon 色带和基础图替换入口已移除。原 PMX 色图、Alpha、Sphere 与描边权重继续按原用途使用。源贴图缺失时明确报错，需在 MMD 原材质中修复后应用。

## 局部调色

顶部 **统一肤色** 同步调整当前主体的脸和已识别的独立身体皮肤，用于对照游戏截图。先点击一次“更新材质”接入，之后拖动立即预览，无需重复应用。

- 色调：白色不额外染色，保留当前默认肤色；选择偏暖或偏冷的浅色调整整体肤色。
- 亮度：1 保持原亮度；略微降低或提高以匹配截图。
- 饱和度：1 保持原饱和度；偏红时可先适当降低。
- 重置：仅恢复上述三项，不清除下方单材质调色或改变灯光。材质面板的“重置参数”也保留这些调色。

调节保存在当前角色主体上，不影响其他角色。混合衣装和皮肤的图集不自动整片染色，可在下方按材质微调；基础脸影和 SDF 脸影共用相同调色。色调为白色、亮度 1、饱和度 1 时保持当前版本默认效果；0.6.3 的默认效果为偏粉肤色。

材质列表只放在此处。颜色、亮度、饱和度、不透明度实时更新当前材质，不影响其他角色。材质识别默认折叠，提供用途修正及资源对应结果。未识别项明确提示指定用途，不自动套用错误着色。

## FBX 自动对应

只解析二进制 FBX 的材质连接、第一 UV 层、三角面和漫反射图引用。支持 ByVertice / ByPolygonVertex、Direct / IndexToDirect UV 与 ByPolygon / AllSame 材质映射。实际对应按唯一候选、原始 UV 三角面和 0.8 像素位置容差核对；重新划分三角面时还核对 UV 区域覆盖；改色不会单独导致拒绝。改动 UV 的区域保持基础响应。

M.G / M.B 用于金属与高光遮罩，A.G 用于光滑度，N.RG 重建法线、N.B 提供阴影偏置。D 图仅识别资源，不替换 PMX 颜色；原始图 Alpha 不替换 PMX 的透明覆盖。

脸部必须对应到原始脸材质，并由其 `_LightTex` 明确引用 Face Lightmap。旧版导出缺少贴图名称时，仅在原始脸材质声明了非空脸影引用、FBX 列明唯一脸影资源且 UV 对应通过时接入。匹配成功的脸部材质启用共享 SDF，未对应的附加脸部材质保留基础脸影；界面显示匹配数量。不同角色可匹配不同共享图，不按性别或角色名猜图。

## 场景、打光与相机

场景载入参考 Hoyo-GI-Toon：城市露台／舞台各自带布景、主光、相机、世界；角色不移动。切换和移除仅清理本模块拥有的资源，保护用户添加与复用的数据，移除时恢复未被手动改选的原引用。

打光预设为默认光、柔和正面、侧面塑形、背光轮廓。每个预设记住自身参数，可选择场景现有主光。点光、面光和聚光以头部到灯光的位置确定材质方向；太阳光使用旋转方向。

内置场景的主光与插件打光预设互斥：启用打光预设时暂停场景主光，保留补光；重新选择场景主光会恢复它并停用插件预设光。仅管理本插件拥有的灯光，不隐藏用户额外添加的灯。

相机使用场景原生选择框。相机对齐当前视角、看向相机和渲染分别操作；看向相机可关闭并移除自己的眼骨约束，原动作继续保留。分辨率、动画渲染和图片保存使用 Blender 原生面板。

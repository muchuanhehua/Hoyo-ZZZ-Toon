# 使用流程与实现边界

## 模型与映射

在 Object Mode 选择 MMD 根、骨架或网格，点击“扫描当前选择”。也可以通过 MMD Tools 导入新的 PMX。已有模型只扫描当前数据，不重复导入或修骨；新导入关闭清理、合点和额外轴向重写。

模型下拉框是应用、恢复和预览的目标。自动识别使用 MMD 中日英文材质名与 Blender 材质名；通用未命名项仅在基础贴图名称具有明确的头发／身体语义时推断。未分类项必须指定用途。用途与贴图开关变化后点击“应用材质”。颜色、阴影、描边及脸部偏移实时更新。

当前开发用多角色共享默认参数验证基础效果，不建立单角色配置。面板中的通用映射修正仍可用于用户模型，批量对照没有使用人工用途覆盖或逐角色调参。

“替换基础贴图”只改变本插件映射。源材质、源贴图路径和色彩空间不改写。基础色引用缺失会中断装配，错误显示在对应材质；可补充贴图或明确选择“保留原材质”。所选 Toon / Sphere 引用缺失同样中断；不需要该效果时可以明确关闭。

## PMX 语义

- 基础色和材质 Alpha 决定颜色与覆盖率；纯色材质可直接使用。
- 未接入增强图时，高光遮罩参考 PMX Specular，主体保留小幅通用响应，粗糙度参考原 shininess；头发不凭空生成贴图高光。“表面高光”是统一强度，0.4 默认 0.2。
- Toon 是 PMX 色带；MMD 共享 Toon 根据导入器的明确索引解析。
- Sphere 分别保留关闭、相乘、相加和附加 UV 用途。模式非零但没有贴图引用时记录“未参与”，不凭模式生成一张游戏数据图。
- 独立眼部、眉睫、口腔与叠层沿用原 Alpha。眼部高光来自模型的实际眼层；表情叠层单独识别。
- 材质 Alpha 不低于 0.999 的虹膜、眼白采用 EEVEE Dithered 深度覆盖，防止共享图集内的透明像素让整个眼材质进入混合透明排序；纹理 Alpha 仍参与覆盖率，原数据不改写。
- 独立头发使用 Dithered 覆盖；若透明头发材质的几何与前面的材质层重合，则保留 Blended 叠加，用于共面毛片和头发高光。重合检测采用约模型高度百万分之一的坐标精度，依据源材质槽顺序，不移动或删改原面。
- 描边读取 PMX 材质开关、边线颜色、宽度及 `mmd_edge_scale` 顶点组。眼口和叠层默认不生成外壳。

## 基础描边

0.5.1 的新扫描默认总线宽为模型高度的 0.15%，再乘 PMX 材质线宽、顶点边线权重和用途倍率：脸部 0.40、独立皮肤 0.55、头发 0.85、其他主体 1.0。单位为场景长度，投影后会随距离变细，不是固定像素描边。

“描边跟随底色”默认 0.90，在 PMX 原边线色与基础贴图原色之间混合；“描边亮度”默认 0.18，降低时边线更深。脸和独立皮肤使用暖色调，其余主体和头发使用冷色调；源 Alpha 和纹理 Alpha 继续决定覆盖。皮肤倍率只作用于识别出的独立皮肤材质，衣装与皮肤混用同一材质时仍按主体用途处理。

这些参数在新版描边上即时刷新。“重置共用描边参数”按当前模型高度恢复统一默认值，不改变身体配色、增强图或脸影绑定。旧工程重置后需点击“应用材质”启用新的用途倍率和线色节点；只打开旧工程会保留原显示。

## 脸部与场景

基础脸影优先使用左右眼骨建立头部坐标，头部控制器跟随指定头骨；指定太阳光提供方向。缺少眼骨时使用 MMD 导入后的骨架局部轴建立基础参照，面板显示实际方向来源。头骨仍是必需输入；非标准朝向可用“脸部方向偏移”修正，更多显式轴向校准留待后续。

“基础脸影”由头部方向与表面法线近似得到；法线与头部前向的混合比例为 0.65／0.35，所有模型共用。0.5 将原生 Diffuse / Shader to RGB 接收器朝向主光，保留刘海和场景物体的遮挡，避免用面部法线再计算一次漫反射而压暗整脸。身体和头发也通过 Diffuse / Shader to RGB 接收实际灯光与阴影。

0.2.0 增加“共享 Lightmap / SDF”模式：先核对模型的原始资源对应与脸部 UV，再使用“选择共享脸影图”绑定图像、选择 SDF 并重新应用。不同共享资产需要分别匹配；默认仍是基础模式，缺少或无效的 SDF 输入会在提交前报错，保持当前材质。按模型绑定资源不建立角色专属风格预设。

“角色主光”同时驱动身体和头发的明暗方向；有受光主体时必须绑定 Sun，即使没有脸部材质。0.5 的身体／头发使用“表面阴影位置／过渡”，按亮面、浅影、深影形成颜色；“头发明暗偏移”单独控制发束的受光分界。皮肤与脸部使用共用暖色控制。PMX 色带混合默认 0，可按需要保留原色带；不把 Toon 当作游戏 Lightmap。场景接收器保留遮挡，灯光色度只相乘一次。

头发使用已匹配 M.B 的图形高光和亮部柔化；缺少可靠控制图时不添加固定横向白带。“暗部环境染色”控制冷色暗部补偿：高亮原色和已经饱和的原色受到较小影响。宽反射依据主光、观察方向、金属／高光遮罩和光滑度构造，是风格化反射，不是完整环境反射追踪。旧版工程继续可显示；点击“重置共用表面参数”并重新应用，采用 0.5 的统一默认值。打开工程不会静默重置已有参数。

SDF 通过外部 Closure 采样原 UV 和左右镜像 UV，以 R 与 Alpha 生成脸影；Alpha 仍是脸影数据，原 PMX 覆盖率单独保留。独立数据副本使用 Non-Color／Channel Packed，与基础色缓存区分，不改源图像。统一 Sun-facing Diffuse 接收器保留真实投影和环境受光，再与 SDF 组合。它不是独立 shadow-only 通道；多灯／强环境光需按场景检查。

“阴影位置／阴影过渡”作用于基础脸影；SDF 脸影使用共用方向曲线与边界门限。“脸部阴影颜色”作用于两种脸影。图像或模式变化后需重新应用；头部方向、主光和颜色等现有参数可以刷新。资源绑定随工程保存，保存工程可用 Blender 的 Pack Resources 内嵌贴图。

### 原始增强图

“原始增强贴图目录”只指定资源位置，不是角色风格配置。目录中的配套 `_D / _M / _A / _N` 先按材质实际使用的三角面 UV 采样核对；不同候选过于接近时拒绝自动绑定。选中候选后仍逐面检查，未通过区域不启用数据响应。状态显示于材质诊断。

基础图被改色、但原始几何 UV 已独立确认时，可选择 `hzz-uv-correspondence` JSON。它使用基础图内容、完整 UV 点集、四张资源摘要与已核对的 UV 范围，不保存角色名或风格参数。同一份资源证据可供多个模型使用。若资源摘要改变，应用会明确中断并保留当前显示。

M.R 是数值 ID，M.G 是金属度，M.B 是高光遮罩；A.G 是光滑度；N.RG 重建切线法线的 Z，N.B 是明暗偏置。A.R／A.B 未自动解释为 PMX 透明度或自发光。图像使用本插件的 Non-Color / Channel Packed 副本；源 UV、贴图及色彩空间保持不变。资源图和核对证据不随插件包分发。

已内嵌图像的工程可直接渲染。重新应用增强材质仍需要原始资源目录和所选核对文件可访问；“恢复原材质”不需要读取这些外部证据。

“创建／进入预览场景”创建独立 EEVEE Scene，拥有单独的低环境光 World、太阳光、相机和输出设置。初始构图同时考虑模型宽度、高度及输出比例。模型对象共享姿态和材质，源场景的 World、相机与渲染引擎不被替换。已有预览会复用；相机支持用户继续调整。

渲染使用 Blender 原生当前场景。分辨率、输出目录、图片保存与动画渲染由 Blender 管理。

## 使用已有背景

使用 City-Terrace 等已有 EEVEE 场景时，在该场景导入或接入模型，指定“角色主光”后直接应用材质，使用原场景相机渲染。0.5 示例使用同一套侧主光、天空补光和背光，三角色无独立调灯；灯光链接使背景保留原场景照明。压力检查关闭补光并把主光旋转 180°。此前批次使用原场景灯光，详见各批次记录。

“创建／进入预览场景”会建立前述独立预览。City-Terrace 原始背景、相机与贴图仅作为外部验证资源；插件包不附带背景资产。多个模型按统一机位分别对照，体型和默认姿态会影响画面占比。

## 保存与恢复

角色映射、源数据引用、派生网格和控制器随工程保存。重复应用先构建新资源，再替换旧资源；资源读取或构建失败时恢复当前显示状态。“恢复原材质”切回源网格、原材质槽及链接方式，并移除本插件渲染修改器。

预览场景、相机与灯光保留。源网格引用被外部操作改变时，恢复会明确中断，不覆盖未知修改。

## 已验证与后续

0.5.1 在三角色原有 City-Terrace 工程中重新检查共用描边：近远机位、两侧与背面、六项参数中适用项的画面响应、旧版更新、重复应用、恢复及保存重开通过。实际 PMX 基础生命周期和脸部遮挡检查已重跑。以下 0.5 的全库、多方向脸影与 SDF 检查为保留的基线，本次未扩大重跑。

0.5 在 Blender 5.2.3 LTS / MMD Tools 4.5.14 的独立后台进程中验证。BASIC 和 SDF 的装配、参数、回滚、恢复和保存重开通过；全部 49 个默认主体实际尝试，46 个出图并通过原数据与恢复检查、3 个缺图中断、运行失败 0。

当前 City-Terrace 的艾莲、青衣、薇薇安使用相同的 21 项参数和灯光，完成全身、侧后方、背光、实际头骨 ±40° 与画面外遮挡检查。三个内嵌图像的工程重开、重新应用与恢复通过；新共用配色控制均有可见响应。基础脸影取消重复受光后也通过实际遮挡检查。详细证据与游戏截图对照见源码开发记录。

材质参数目前在装配时读取；材质／组 Morph 的逐帧动态桥接尚未完成。完整 VMD、物理演出、GUI 撤销重做、同场景多角色隔离与不同版本 Blender 尚未验证。新角色需先检查用途与资源，游戏外观尚未验收。

共面贴花仍使用混合覆盖，复杂交叉透明的排序受源网格与材质组织影响。本轮静态叠层判断不等于透明层在所有 Morph／动作下已验证。

# Hoyo-ZZZ-Toon

面向绝区零 PMX / MMD 模型的 Blender 5.2 卡通渲染插件。**0.6.0** 简化为六个面板，并自动对应 FBX 原始资源。

[下载 0.6.0](https://github.com/muchuanhehua/Hoyo-ZZZ-Toon/releases/tag/v0.6.0)。已有 Hoyo-ZZZ-Toon 扩展源可直接检查更新；更新源地址保持不变：`https://raw.githubusercontent.com/muchuanhehua/Hoyo-ZZZ-Toon/main/release/index.json`。

## 开始使用

1. 启用 MMD Tools，在侧栏 **Hoyo-ZZZ-Toon → 角色管理** 导入模型，或在主体选择框选已有角色。右侧眼睛按钮切换骨骼显示。
2. 在 **材质** 点击 **应用材质**。有配套原始资源时，可先选择 **FBX 目录**；插件自动核对材质引用和 UV，并接入可匹配的增强图与脸影。
3. 调整阴影位置、明暗过渡、衣料光泽和描边；首次应用后实时预览。局部颜色、亮度、饱和度、不透明度位于 **局部调色**。
4. 按需展开 **场景** 载入城市露台或舞台，展开 **打光** 启用预设。在 **相机** 对齐视角、启用看向相机或渲染。

六个独立面板依次为角色管理、材质、局部调色、场景、打光、相机；仅场景和打光默认折叠。渲染、分辨率和保存使用 Blender 原生功能。

**描边粗细是无单位倍率**：1 为按角色身高计算的默认值，0 关闭，可调到 3，手动输入上限 20。默认绝对宽度仍为身高的 0.15%，并保留脸、皮肤、头发的共用倍率与 PMX 局部权重。

## 原始资源

选择含 `.fbx`、`Textures` 和 `Materials` 的对应服装资源文件夹。插件只读解析 FBX，不导入第二套模型；使用原始材质的贴图引用、UV 三角面和像素误差范围验证对应。无需用户准备 UV 对应 JSON。无法唯一对应的区域保留基础响应，可在局部调色的“材质识别”中查看原因。

基础颜色始终来自 PMX 自带贴图。PMX Toon 和基础贴图替换已从插件工作流移除；PMX 的源材质与原图保留，支持恢复。增强图控制表面响应，脸影按明确的原始引用接入；没有资源时直接使用基础渲染。

## 旧工程

旧工程打开后保留已有材质。选中主体后点击 **更新材质**，迁移到 0.6 链路并移除旧 PMX Toon。原有增强图目录会转换为对应 FBX 目录；旧 UV 对应 JSON 不再参与运行。局部颜色与原模型数据继续保留。

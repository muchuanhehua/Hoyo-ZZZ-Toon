# Hoyo-ZZZ-Toon

面向绝区零 PMX 角色与 MMD 工作流的 Blender 渲染插件。当前源码为 **0.5.1 共用描边调整＋基础外观与共享脸影 SDF**，使用 Blender 5.2 / EEVEE，PMX 导入依赖 MMD Tools。历史包保留。

[下载 0.5.1](https://github.com/muchuanhehua/Hoyo-ZZZ-Toon/releases/tag/v0.5.1) · [版本说明](release/0.5.1.md)

可直接安装 Release 中的 `hoyo_zzz_toon-0.5.1.zip`，也可在 Blender **偏好设置 → 获取扩展 → 仓库 → 添加远程仓库** 中添加以下地址，刷新后安装 **Hoyo-ZZZ-Toon**，以后可在同一入口检查更新：

```text
https://raw.githubusercontent.com/muchuanhehua/Hoyo-ZZZ-Toon/main/release/index.json
```

支持导入 PMX、接入已有 MMD 模型、修正材质用途、基础 Toon、独立眼层、基础脸影／共享 SDF、PMX 描边，以及独立预览场景和原材质恢复。参数、资源绑定和映射随 `.blend` 保存。

当前优先用多个角色、统一默认参数检查共用基础渲染。自动识别按材质名称与明确的基础贴图语义工作；没有角色姓名分支、单角色预设或专属材质补丁。

0.5 根据游戏截图与 RandomPlayToon 的完整展示链路，重构亮面／浅影／深影配色、受原色约束的冷色暗部、暖色皮肤、头发受光分区，以及随主光和视角变化的宽反射。白衣、浅色头发保留高光空间，深色衣料增加曲面层次。原有增强图核对、透明覆盖、共享 SDF 和恢复流程继续保留。

基础脸影取消重复漫反射压暗，头部／法线只生成一次分区，原生接收器继续保留遮挡。该修正对所有基础脸材质共用，不依赖 SDF 资源或单角色设置。

0.5.1 根据三角色游戏截图调整基础描边：总线宽从身高 0.07% 改为 0.15%，脸／独立皮肤／头发分别使用 0.40／0.55／0.85 倍率。线色 90% 跟随基础贴图原色，亮度 0.18，皮肤偏暖、衣装与头发偏冷。侧栏提供这些共用控制。旧工程先点 **重置共用描边参数**，再 **应用材质**；打开工程不会自动改写已有描边。

## 使用

1. 在 Blender 5.2 中启用 MMD Tools，安装本项目扩展 ZIP。
2. 打开 3D 视图侧栏 **Hoyo-ZZZ-Toon**。选择已有模型后点击 **扫描当前选择**，或使用 **导入 PMX**。
3. 检查材质用途；未分类项需要指定。缺失贴图时修正基础贴图，或明确关闭未使用的 Toon / Sphere。
4. 有原始数据图时，指定 **原始增强贴图目录**（配套 `_D / _M / _A / _N`）。可选 **已核对 UV 对应** 文件用于基础图被改色、但资源与 UV 已独立核对的资产。没有增强图也可使用基础响应。
5. 点击 **创建／进入预览场景**，再点击 **应用材质**。也可使用当前 EEVEE 场景并指定太阳光。
6. 调整颜色、阴影、描边和脸影方向；用途或贴图设置变化后重新应用。旧工程先点 **重置共用表面参数**，再重新应用，可采用新版统一默认值。
7. 使用 **渲染当前场景** 或 Blender 原生渲染。**恢复原材质** 还原源网格与材质，预览场景继续保留。

脸影默认使用“基础脸影”。已有匹配资源时，在“脸部与灯光”选择“共享 Lightmap / SDF”，用“选择共享脸影图”绑定已核对与模型 UV 对应的图像，再重新应用。不同模型可以引用不同共享资产；不会自动给所有角色套同一张 Female 图。插件创建独立 Non-Color／Channel Packed 数据副本，源图像设置保持独立。资源不随插件分发。

0.4 将材质输入核对、通道解码、表面明暗、头发响应和反射分开。M.G／M.B 控制金属与高光，A.G 控制光滑度，N.RG 重建法线、N.B 控制明暗偏置；M.R 只作为数值区域 ID，不猜测皮肤／金属用途。发片与眼层继续使用原 PMX Alpha，A.R 不替换覆盖率。场景色彩只作用一次，避免重复压暗。

详见 [操作与边界](docs/workflow.md)。设计进度见 [开发记录](design/DEVELOPMENT.md)，来源见 [研究基线](docs/upstream-baseline.md)。

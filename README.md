# Hoyo-ZZZ-Toon

面向绝区零 PMX / MMD 模型的 Blender 5.2 卡通渲染插件。当前版本为 **0.7.0**。应用材质时自动生成相机约束描边和选择性刘海透眼，保留现有偏粉肤色、实时调色与主光互斥。

脸与身体皮肤使用同一套颜色、遮挡和场景光色响应，默认光与内置场景主光互斥。0.6.3 将这套共用配色调回偏粉；旧工程选择主体后点击“更新材质”生效，已有统一肤色调节、局部调色与原贴图保留。

**局部调色 → 统一肤色** 提供色调、亮度、饱和度和重置，用于对照游戏截图。脸与已识别的独立身体皮肤同步实时变化；白色色调、亮度 1、饱和度 1 表示不额外调色，保留当前版本的默认偏粉效果。旧工程先点一次“更新材质”。

[下载 0.7.0](https://github.com/muchuanhehua/Hoyo-ZZZ-Toon/releases/tag/v0.7.0)。已有 Hoyo-ZZZ-Toon 扩展源可直接检查更新；更新源地址保持不变：`https://raw.githubusercontent.com/muchuanhehua/Hoyo-ZZZ-Toon/main/release/index.json`。

## 开始使用

1. 启用 MMD Tools，在侧栏 **Hoyo-ZZZ-Toon → 角色管理** 导入模型，或在主体选择框选已有角色。右侧眼睛按钮切换骨骼显示。
2. 在 **材质** 点击 **应用材质**。有配套原始资源时，可先选择 **FBX 目录**；插件自动核对材质引用和 UV，并接入可匹配的增强图与脸影。
3. 调整阴影位置、明暗过渡、衣料光泽、描边和刘海透眼。透眼无需手工选面，按 **F12** 查看完整合成；局部颜色、亮度、饱和度、不透明度位于 **局部调色**。
4. 按需展开 **场景** 载入城市露台或舞台，展开 **打光** 启用预设。在 **相机** 对齐视角、启用看向相机或渲染。

六个独立面板依次为角色管理、材质、局部调色、场景、打光、相机；仅场景和打光默认折叠。渲染、分辨率和保存使用 Blender 原生功能。

**描边粗细是无单位倍率**：1 为按角色身高计算的默认值，0 关闭，可调到 3，手动输入上限 20。默认绝对宽度仍为身高的 0.15%，并保留脸、皮肤、头发的共用倍率与 PMX 局部权重。

相机约束描边默认开启，会跟随当前渲染相机与分辨率限制过大的外扩。**材质 → 描边与透眼** 可调整最大像素宽度，或关闭相机约束恢复原来的法线外扩。

**刘海透眼** 自动依据头部、脸和眼的位置识别前刘海，并结合实际可见性、深度、视角淡出与标准闭眼形态键控制透出。眼皮、手、侧发、后发、其他角色与场景物体继续遮挡。缺少可靠眼部／刘海区域时显示原因；不使用角色专属面号或预设。

透眼显示于最终图片和动画合成，常规材质预览不包含完整效果。辅助数据由插件管理，无需切换到辅助场景或手动运行脚本；恢复原材质时一并移除。每个启用透眼的目标有额外可见性渲染开销。

## 原始资源

选择含 `.fbx`、`Textures` 和 `Materials` 的对应服装资源文件夹。插件只读解析 FBX，不导入第二套模型；使用原始材质的贴图引用、UV 三角面和像素误差范围验证对应。无需用户准备 UV 对应 JSON。无法唯一对应的区域保留基础响应，可在局部调色的“材质识别”中查看原因。

基础颜色始终来自 PMX 自带贴图。PMX Toon 和基础贴图替换已从插件工作流移除；PMX 的源材质与原图保留，支持恢复。增强图控制表面响应，脸影按明确的原始引用接入；没有资源时直接使用基础渲染。

## 旧工程

旧工程打开后保留已有材质。选中主体后点击 **更新材质**，接入自动描边和透眼。原有增强图目录会转换为对应 FBX 目录；旧 UV 对应 JSON 不再参与运行。局部颜色、原模型数据、基础脸影与 SDF 链路继续保留。

# 材质输入与质感重做

日期：2026-10-31。状态：私有研究与原型，外观未通过，未合并。

## 问题与范围

0.3 的基础链路主要依赖 PMX 漫反射、Toon、Sphere 和 Specular。三名代表的多个源材质 Specular 接近零，无法由此恢复游戏的皮肤、布料、金属与袜面响应。仅修改全局颜色，或直接复制 Kythera 的默认 Body 效果，均未解决质感差距。

艾莲、青衣、薇薇安继续共用实现和风格参数。源 PMX、原始图像、City-Terrace 与前台工程保持；原始 JSON 中自带的材质参数是资产输入，不新增角色预设。运行源码与 0.3.0 包冻结，不把诊断原型当作新候选。

## 已核对的输入

| 输入 | 当前理解与限制 |
|---|---|
| D | 颜色图；图集可以由多个原始材质共用，不能由 D 唯一选定材质 JSON |
| M.R | 五段材质区域 ID，不能把白色统一解释为皮肤遮罩 |
| M.G／M.B | 金属度／高光遮罩；与 PMX Specular 分开 |
| A.R／A.G | 透明输入／光滑度；原型继续保留 PMX 覆盖，尚未移植全部 A.R 行为 |
| A.B | Matcap／自发光的打包输入，分拆依赖二者开关；普通材质不能在 0.2 处截断 |
| N.RG／N.B | 切线法线 XY／漫反射偏置；从 XY 重建 Z，不把 B 当作法线 Z |
| UI 材质 JSON | 原资产的区域颜色、高光、Matcap、折射等设置；并非只有颜色图与法线图 |
| Matcap | 独立纹理、区域、遮罩、混合与采样设置；颜色空间、折射与完整映射仍需继续核对 |

通道理解来自本地原始材质数据，并与 HoyoToon、Zenlight 的主体实现交叉核对。社区实现不是游戏官方源码，不声称当前原型与游戏等价。

## UV 与材质身份

原生参考工程的部分 UV 以半精度保存。比较双方半精度值后，再用原始 UV 的纹理像素误差与三角形对应核对；没有修改 PMX 的 UV。对所有额外 UV 流作过检查，目前三角色最优均为主 UV，部分青衣与艾莲区域确有编辑差异。

当前数据图置信区域要求原始 UV 点距原生候选不超过 0.8 个纹理像素；派生 CORNER 属性控制法线与反射输入的有效范围，颜色基底保持连续。此阈值只是诊断筛选，不证明像素语义或全部材质已经匹配。完整输入覆盖与未匹配区必须分开记录。

青衣和薇薇安的同一 Body_2 图集分别存在 Body_2、Hair_T 原生材质。旧探针按图集选 JSON，属于临时候选，不能据此认定材质参数正确。后续先匹配原生材质的三角面／UV 区域，再选择 JSON；UV 重叠且无法唯一确定时保留未匹配状态。

资料库扫描的 749 份 JSON 可提供纹理引用线索；跨文件 `m_PathID` 不保证全局唯一。艾莲旧材质未命名的 Matcap 引用只作为候选，不能凭“全库只有一个名字＋本地存在文件”自动确认。工具默认拒绝这些推断；需要复现旧诊断时显式传入 `--allow-provisional-inputs`。

## 实际试验结果

证据根目录为忽略的 `.verification/material-response-20261031/`。

- `surface-v2/`：移写 Kythera V2 的覆盖前颜色核心，与原生控制最大线性差分别约 0.000443、0.000122、0.000244。数学对照通过，但 City-Terrace 中仍明显平，未采用。
- `authored-v2/`：接入原始数据与材质 JSON 的诊断原型。错误拆分非自发光材质的 A.B，袜面出现硬边反光；保留失败图与报告。
- `authored-v3/`：修正遮罩条件及 Overlay 围绕中性灰的公式，三角色重新渲染；艾莲与薇薇安的硬边消失。头发、衣料、皮肤与全局颜色仍偏离游戏，未通过外观复核。
- `authored-v4/`：增加按原资产高光形状与范围的解析式探针。出现更明显的发丝高光，但局部过白；没有解决整体质感，未采用。部分图集到材质的对应仍属上述临时候选。
- `shared-light-v1/`：在三个私有工程中通过 EEVEE 灯光链接分别限制背景原灯光与统一角色侧主光、冷色补光、暖色背光。实际方向属性已核对，源数据与输入副本摘要保持，但视觉改善不足，未采用。

上述三个代表的实际运行报告分别记录输入摘要与源数据保持。没有重跑全部角色、动画、材质恢复或新核心的完整生命周期，不沿用 0.3 的结果证明新原型稳定。

后续核对 RandomPlayToon 时发现，本项目旧解析式高光的视线向量取反。工具代码已纠正；`authored-v4/` 保存错误方向的原始结果，不作为正确高光对照。该旧原型尚未在修正后单独重跑。新的共用核心隔离对照与实际限制见 [RandomPlayToon 研究](randomplay-reference.md)。

## 继续实施的门槛

1. 先完成图集内原始材质区域对应，排除 Body／Hair_T 参数混用；缺失或歧义明确中断该增强绑定。
2. 对照原始资源核实 Matcap 色彩空间、折射与遮罩，保留开关对照；解析式高光的能量与形状必须在多角度保持合理。
3. 在三角色共用条件下核对皮肤的暖暗过渡、衣料的宽高光、金属的窄反光、袜面的连续渐变及发丝高光。先看局部，再看全身、侧后与背光。
4. 材质响应有效后再处理共用环境配色与轮廓光，不能用染色替代体积与材质差别。
5. 三角色画面对照成立后，才合并受归属与恢复管理的实现、补做对应生命周期与扩大样本。外观审阅、运行检查与构建继续分别记录。

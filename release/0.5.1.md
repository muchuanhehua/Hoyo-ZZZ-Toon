# Hoyo-ZZZ-Toon 0.5.1

本版调整共用基础描边，使衣装轮廓更清楚、脸部保持细线、浅色头发的边线随原色变化。艾莲、青衣、薇薇安使用同一套参数，没有单角色预设。

## 变更

- 总线宽为身高的 0.15%，脸／独立皮肤／头发倍率为 0.40／0.55／0.85。
- 描边 90% 跟随基础贴图原色，亮度 0.18；脸与独立皮肤偏暖，衣装与头发偏冷。
- 新增“基础描边”控制区和“重置共用描边参数”。继续保留 PMX 材质／顶点边线权重、原 Alpha 与纹理覆盖。
- 保留 0.5.0 共用基础表面、共享脸影 SDF、增强图核对及原材质恢复。

## 安装与更新

需要 Blender 5.2 或更高版本；已验证 Blender 5.2.3 LTS。导入 PMX 需要单独启用 MMD Tools。

从本次 Release 下载 `hoyo_zzz_toon-0.5.1.zip`，在 Blender 偏好设置中使用“从磁盘安装”，安装后启用 Hoyo-ZZZ-Toon。

也可在“获取扩展”的仓库菜单添加远程仓库：

```text
https://raw.githubusercontent.com/muchuanhehua/Hoyo-ZZZ-Toon/main/release/index.json
```

刷新后安装 Hoyo-ZZZ-Toon；后续可通过此仓库检查更新。三维视图侧栏中提供 Hoyo-ZZZ-Toon 面板。

旧工程要采用本版描边，点击 **重置共用描边参数 → 应用材质**。打开工程不会自动重建既有材质。独立皮肤倍率只作用于已识别的独立皮肤材质，混合图集仍使用主体线宽。

## 验证范围

三角色完成统一参数、近远机位、两侧与背面、参数实际响应、重复应用、原数据与覆盖保留、恢复及保存重开检查。基础 PMX 生命周期与真实脸部遮挡检查通过，扩展格式校验通过。

本次为描边专项补丁，0.5.0 的 49 主体与 SDF 核心验证保留为历史基线，没有将其记作 0.5.1 的全库重跑。未扩大验证完整动画、物理、GUI 撤销重做或同场景多角色隔离。

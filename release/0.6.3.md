# Hoyo-ZZZ-Toon 0.6.3

默认统一肤色恢复为此前的偏粉配色：亮面 `(1.02, 0.77, 0.79)`，暗部 `(0.76, 0.44, 0.54)`。脸与身体皮肤共用它们，继续保留统一遮挡、场景光色和主光互斥修复。

旧工程选择主体，点击一次“更新材质”即可采用新默认值。迁移只处理 0.6.1／0.6.2 的旧中性默认配色；已有的统一肤色调节、局部调色及其他自定义配色保留。

“局部调色 → 统一肤色”仍可实时调节色调、亮度与饱和度。白色、亮度 1、饱和度 1 表示不额外调色，保留偏粉默认效果。材质参数重置使用偏粉默认配色。

克拉蕾、千夏、艾莲、青衣、薇薇安的实际渲染对照，以及旧默认迁移、自定义调色保留、失败回滚、保存重开与重置检查通过。本机已通过原生扩展安装并验证；本次发布使用同一冻结包，更新源地址保持不变。

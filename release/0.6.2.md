# Hoyo-ZZZ-Toon 0.6.2

包含统一肤色修复和可调肤色，兼容从 0.6.0 直接升级。

在“局部调色”顶部增加“统一肤色”，可用色调、亮度和饱和度对照游戏截图。脸和已识别的独立身体皮肤同步实时调整；默认白色、亮度 1、饱和度 1 保持 0.6.1 的外观。

同时纳入此前 0.6.1 的修复：脸与身体共用肤色、遮挡和场景光色响应，减弱固定粉色／紫色染色；内置场景主光与插件打光预设互斥，避免叠加，保留补光。0.6.1 不另设公开 Release。

旧工程先点击一次“更新材质”，之后拖动调色即可预览。统一肤色的“重置”只恢复这三项，下方单材质调色继续保留；保存工程和重新应用保留调整值。混合衣装与皮肤的图集不自动整片染色。

本次实际验证：千夏、艾莲、青衣、薇薇安的默认画面对照、实时调色、非皮肤材质与 Alpha 保留、重新应用、保存重开、恢复及原始数据保留；千夏另核对两个重置操作的作用范围。基础脸影、SDF 和身体皮肤在白光、暖光、冷光下的调色响应一致。未扩大到全部角色或完整动画回归。

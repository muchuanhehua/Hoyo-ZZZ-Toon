# Hoyo-ZZZ-Toon 0.6.0

这一版简化应用流程和面板。需要 Blender 5.2 与 MMD Tools；下载 `hoyo_zzz_toon-0.6.0.zip` 从磁盘安装，或在已添加的 Hoyo-ZZZ-Toon 扩展源中检查更新。

更新源沿用：`https://raw.githubusercontent.com/muchuanhehua/Hoyo-ZZZ-Toon/main/release/index.json`。

## 怎么使用

1. 启用 MMD Tools，在“角色管理”导入 PMX，或选择已有完整角色。
2. 有原始资源时，在“材质”选择对应的 FBX 目录；没有也可直接应用。
3. 点击“应用材质”。随后四个常用参数和局部调色实时生效；更换资源目录后点击“更新材质”。
4. 场景、打光按需展开；相机对齐、看向相机和渲染在相机面板。

## 本版变化

- 六个独立可展开面板，仅场景与打光默认折叠。
- 移除手动扫描、PMX Toon、基础贴图替换以及手动 UV 对应输入。
- FBX 目录自动对应增强图与 SDF 脸影，PMX 原始底色保留；不导入第二套模型。
- 材质区保留阴影位置、明暗过渡、衣料光泽和描边粗细。描边默认 1、0 关闭，以角色身高计算，不再显示米。
- 材质列表移至局部调色；支持颜色、亮度、饱和度和不透明度。
- 参考 Hoyo-GI-Toon 接入场景、打光与原生相机操作，保持 ZZZ 着色核心。

## 验证

维琳娜、艾莲、青衣、薇薇安的自动资源对应、全身／背光渲染、重复应用、失败回滚和原材质恢复通过。新导入／已有模型接入、保存重开、场景切换恢复、中文界面、原生撤销重做和相机对齐通过。

实际 ZIP 已通过 Blender 原生扩展校验，并在独立进程加载解包载荷，验证 PMX／FBX 应用和两个自带场景出图。安装包 4,046,817 字节，SHA256：`454d7218024411f2604f4a488c5c17bbefe3529e9427beabb7c4311ba3b7f3cb`。

UV 不对应的区域保留基础响应；艾莲附加脸材质保留基础脸影，主要脸部使用 SDF。资源对应结果可在局部调色的识别详情查看。

旧工程选中主体后点击“更新材质”迁移新链路；原始数据不覆盖。安装包沿用已验证候选 ZIP，其内文档保留冻结时状态；正式发布说明以本页为准。具体证据见 [开发记录](https://github.com/muchuanhehua/Hoyo-ZZZ-Toon/blob/main/design/DEVELOPMENT.md)。

# Hoyo-ZZZ-Toon 0.5.2

修复中文 Blender 中“创建／进入预览场景”无法使用的问题。

开启“新建数据”翻译后，Blender 会将新建环境的 Background 节点命名为“背景”。0.5.1 按英文名称查找节点，导致创建过程报错；本版改为按节点类型查找，保持中文设置即可正常使用。

更新后依次执行：**导入／扫描模型 → 创建／进入预览场景 → 应用材质 → 渲染当前场景**。已经扫描的模型直接重试创建预览即可。

英文、中文新数据翻译开启／关闭三种设置下的实际操作符新建、场景切换、重复进入均通过。中文预览实渲、创建中途失败回滚和原场景数据保留通过。本版保留 0.5.1 的材质、描边、共享 SDF 与默认参数。

需要 Blender 5.2 或更高版本；本次验证环境为 Blender 5.2.3 LTS。下载 `hoyo_zzz_toon-0.5.2.zip` 从磁盘安装，或在已添加的 Hoyo-ZZZ-Toon 扩展仓库中检查更新。

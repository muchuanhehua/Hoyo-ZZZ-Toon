# Hoyo-ZZZ-Toon 0.6.1 本地修复版

修正脸偏暖黄、身体皮肤偏粉红，以及冷暖光下脸与身体色差被放大的问题。

- 脸和身体共用中性的亮面、轻微暖色的暗部，保持原贴图中的腮红和肤色。
- 基础脸影、SDF 脸影和身体统一实际遮挡及场景光色响应；SDF 方向曲线不变。
- 打光预设与内置场景主光互斥，保留补光，并支持切换恢复。
- 不增加参数或单角色配置。更新后选择主体，点击“更新材质”；旧默认肤色自动迁移，局部调色保留。

千夏、艾莲、青衣、薇薇安以共用参数进行前后、侧光及背光检查。相同底色的基础脸影、SDF 与身体皮肤在白光、暖光、冷光下通过一致性验证。完整记录见开发记录。此版本未单独公开发布，修复已纳入 [0.6.2](0.6.2.md)。

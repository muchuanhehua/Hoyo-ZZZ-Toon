# 0.7.0 自动描边与刘海透眼

应用／更新材质时，自动生成相机约束描边和选择性刘海透眼，无需手工选面、创建辅助对象或运行脚本。

- 描边保留角色身高比例、部位倍率和 PMX 顶点权重，随当前相机及输出尺寸限制外扩；高级设置可调最大像素宽度。
- 自动识别前刘海与眼部范围，正面透出、侧面淡出；眼皮、手、其他头发、其他角色和场景物体继续遮挡，标准闭眼形态键自动控制眼部透出。
- 在最终图片／动画合成中显示透眼；常规材质预览不包含完整效果。材质面板可调整透眼强度，0 关闭透出。
- 保留已有合成器的后处理；恢复原材质时移除辅助资源并还原原合成器和通道设置。
- 基础脸影、SDF、身体着色与当前偏粉肤色不变。

旧工程安装后保持原材质，选择角色点击一次“更新材质”启用。每个启用透眼的角色有额外可见性渲染开销；不要求切换到插件管理的辅助场景。

验证范围和限制见开发记录。私人模型、贴图、对照图与验证工程不包含在安装包或公开源码中。

# 0.8.0 原始头发高光扩缩

选择配套 FBX 并更新材质后，自动使用已匹配的原始头发高光遮罩，无需手工接线或制作遮罩。

在“材质 → 头发高光”调整高光扩缩、边缘柔化与强度。扩缩范围 ±12 个基准像素，负值收窄、正值扩宽；柔化 0 保留边缘，1 为最大柔化。默认扩缩 0、柔化 0、强度 0.45，保持旧版外观。三项控制支持实时更新与关键帧。

未匹配原始遮罩时保留基础响应并显示资源提示。底色图中已经画好的亮纹、基础脸影、SDF、身体着色、描边和透眼算法保持。派生数据随工程保存，恢复原材质时一并清理；私人贴图、模型和验证工程不进入公开载荷。

更新插件后重启 Blender，选择角色点击一次“更新材质”。验证范围与实际证据见开发记录。
